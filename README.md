# mise. — Recipe scaler & purchasing list

A responsive culinary recipe scaling and purchasing-order tool, built with React, TypeScript, Vite, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Features

- Scale the sample Chicken Rendang and Mushroom Soup recipes from a two-portion base to any target yield.
- Edit recipe titles and ingredient names, quantities, units, categories, and wastage; add or remove ingredients and create recipes.
- Smart SI unit promotion between g/kg and ml/L, with a precision-unit toggle.
- Generate a grouped Malay/English purchase requisition with CSV export, print, and clipboard actions.
